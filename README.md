# Clínica Dental Sonrisa

## Descripción del proyecto

Proyecto Intermodular de 2.º SMR.

El objetivo es diseñar e implementar una pequeña infraestructura informática para una clínica dental.

## Integrantes

- Juan
- Pedro
- Ana

## Infraestructura prevista

- 1 servidor
- 3 ordenadores cliente
- 1 router
- 1 switch
- Red Wi-Fi
- Página web en HTML y CSS

## Servicios

- DHCP
- DNS
- Carpetas compartidas
- Gestión de usuarios
- Copias de seguridad
